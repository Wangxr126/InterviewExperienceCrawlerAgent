## 1. 题库浏览（`BrowseView`）

**页面介绍**
- 面向题库检索与练习入口，支持筛选、分页、跳转聊天练习、提交作答。

**核心按钮与实现**
- 查询/筛选：调用 `api.getQuestions()`，按公司/难度/标签等筛选。
- 智能练习：调用 `api.getSmartPracticeQuestions()` 组装训练集。
- 发送到对话：通过父组件 `onSendToChat` 切页到 `ChatView` 并预填消息。
- 提交作答：调用 `api.submitAnswerStream()` 或异步 `submitAnswer + status`。

**占位图**
- `docs/系统梳理/placeholders/placeholder_browse.png`

## 2. 练习对话（`ChatView`）

**页面介绍**
- 与 InterviewerAgent 实时交互，支持流式回复、思考过程展示、会话历史恢复。

**核心按钮与实现**
- 发送：调用 `api.chatStream()`，SSE 接收增量回复。
- 清空：调用 `api.clearChatSession(userId)` 清理会话历史。
- 快捷提问按钮：触发 `prefillAndSend()`，快速填充问题。
- 录音按钮（若开启）：触发 `toggleRecording`，用于语音输入流程。

**占位图**
- `docs/系统梳理/placeholders/placeholder_chat.png`

## 4. 数据采集（`CollectView`）

**页面介绍**
- 全量采集工作台：发现任务、正文抓取、LLM 提取、失败重试、清洗与批量管理。

**核心按钮与实现（高频）**
- 刷新：`loadStats()` + `loadTasks()`。
- 牛客采集 / 小红书采集 / 双平台采集：`api.triggerCrawl(...)`。
- 抓取正文并提取：`api.processQueue()`。
- 提取待处理：`api.extractPending()`。
- 重试失败项：`api.retryErrors()`。
- 重新提取所有：`api.reExtractAll()`。
- 清洗无关帖：`api.cleanData()`。
- 批量重提取：`api.reExtractBatch(task_ids)`。
- 批量删除：`api.deleteTasksBatch(task_ids)`。
- 清除所有：`api.clearAllCrawlData()`。
- 单任务详情：`api.getCrawlerTaskDetail(task_id)`。
- 单任务题目：`api.getTaskQuestions(task_id)`。

**占位图**
- `docs/系统梳理/placeholders/placeholder_collect.png`

## 5. 定时任务（`SchedulerView`）

**页面介绍**
- 对发现任务/处理任务进行可视化编排（cron/interval）。

**核心按钮与实现**
- 新建任务：弹窗提交 `api.createSchedulerJob()`。
- 刷新任务：`api.getSchedulerJobs()`。
- 编辑任务：`api.updateSchedulerJob(job_id, form)`。
- 删除任务：`api.deleteSchedulerJob(job_id)`。
- 启用/禁用：`api.enableSchedulerJob()` / `api.disableSchedulerJob()`。
- 立即执行：`api.runSchedulerJob(job_id)`。

**占位图**
- `docs/系统梳理/placeholders/placeholder_scheduler.png`

## 7. 微调标注（`FinetuneView`）

**页面介绍**
- 两阶段抽取样本的人审、修订、导出、训练配置管理中心。

**核心按钮与实现（核心链路）**
- 刷新统计：`GET /api/finetune/stats`。
- 自动导入日志：`POST /api/finetune/import-all`。
- 修复 merged：`POST /api/finetune/fix-merged`。
- 查看样本/分页：`GET /api/finetune/samples`。
- 样本详情：`GET /api/finetune/samples/{id}`。
- 助手改写：`POST /api/finetune/assist`。
- 标注确认：`POST /api/finetune/label`。
- 导出训练集：`POST /api/finetune/export`。
- 保存训练配置：`POST /api/finetune/run-config`。
- 生成训练脚本：`POST /api/finetune/generate-training`。

**占位图**
