# 意图实现详解（最终版）

## 1) 推荐题目意图
- 触发：用户说“来道题/下一题/出题”。
- 路由：`interviewer_prompt` -> `get_recommended_question`。
- 代码：`backend/tools/interviewer_tools.py` 的 `GetRecommendedQuestionTool.run()`。
- 实现：
  - 读取 `topic/company/difficulty`。
  - 排除用户已做题（`study_records`）。
  - 调 `multi_recall_recommender.recommend(...)` 做多路召回。
  - 返回候选题（Agent 通常只展示一道）。

## 2) 相似题目意图
- 触发：用户说“换个问法/来类似题”。
- 路由：`find_similar_questions`。
- 代码：`FindSimilarQuestionsTool.run()`。
- 降级链路：
  1. Neo4j 向量检索 `search_similar`。
  2. 启用时做 `rerank_candidates` 重排。
  3. 按 company/difficulty/exclude_id 过滤。
  4. 无结果 -> `get_variants`。
  5. 再无结果 -> SQLite 关键词/标签兜底。

## 3) 智能练习意图（推荐+随机）
- 接口：`GET /api/questions/smart-practice`。
- 代码：
  - `backend/main.py` 的 `get_smart_practice_questions`
  - `backend/services/multi_recall_recommender.py` 的 `recommend_smart_practice`
- 核心逻辑：
  - “知识点不足”一路：薄弱点 + 到期复习 + 热门补充召回。
  - 候选放大：`N * SMART_PRACTICE_RECALL_RATIO`。
  - Rerank 取前 N。
  - 再补 M 条随机题。
  - 返回 `smart_type = recommend/random`。

## 4) Reranker 具体实现
- 代码：`backend/services/rerank_service.py`
- 调用：Ollama `POST /api/rerank`
- 入参：`query + documents + top_n`
- 出参：`relevance_score` 排序
- 使用点：
  - `find_similar_questions`
  - `multi_recall_recommender.recommend`
  - `recommend_smart_practice`
- 失败策略：自动降级为原召回分排序，不阻断流程。

## 5) GraphRAG 具体实现
- 前端可视化 GraphRAG：
  - 接口：`/api/user/{user_id}/graph-rag`
  - 数据：`sqlite_service.get_graph_rag_data()`
  - 输出：题库标签共现图 + 用户做题图
- 检索型 GraphRAG（工具侧）：
  - `get_concepts_by_question`
  - `get_related_concepts`
  - `get_questions_by_concept`
  - `get_questions_by_tags`
  - `recommend_by_company`

## 6) 关键配置项
- Rerank：
  - `RERANK_ENABLED`
  - `RERANK_MODEL`
  - `RERANK_OLLAMA_URL`
  - `RERANK_TIMEOUT`
- 检索：
  - `RETRIEVAL_SEARCH_TOP_K`
  - `RETRIEVAL_SCORE_THRESHOLD`
  - `RETRIEVAL_SIMILAR_LIMIT`
- 智能练习：
  - `SMART_PRACTICE_KNOWLEDGE_GAP_COUNT`
  - `SMART_PRACTICE_RANDOM_COUNT`
  - `SMART_PRACTICE_RECALL_RATIO`
  - `SMART_PRACTICE_RERANK_ENABLED`
  - `SMART_PRACTICE_VECTOR_WEIGHT`
  - `SMART_PRACTICE_REVIEW_WEIGHT`
  - `SMART_PRACTICE_POPULAR_WEIGHT`
  - `SMART_PRACTICE_WEAK_TAGS_LIMIT`

## 7) 一句话结论
- 推荐题：多路召回 + 可选 Rerank。  
- 相似题：向量优先，失败逐级降级。  
- 智能练习：知识点不足 N + 随机 M。  
- GraphRAG：前端图可视化 + 工具侧概念检索。
