# 意图与推荐检索实现详解

本文专门回答你提的这块：几种意图（推荐题目、相似题目等）怎么实现，以及 Reranker、GraphRAG 在系统里的具体落点。

**仓库结构索引**：[`docs/README.md`](../README.md)。

## 1. 总体分层

- 意图规则：`backend/agents/prompts/interviewer_prompt.py`
- 工具实现：`backend/tools/interviewer_tools.py`
- 多路召回：`backend/services/multi_recall_recommender.py`
- 重排服务：`backend/services/rerank_service.py`
- 图谱服务：`backend/services/storage/neo4j_service.py`
- 页面图谱接口：`/api/user/{user_id}/graph-rag`

## 2. 主要意图与对应实现

### 2.1 推荐题目（来道题、下一题）

- 触发：Prompt 中出题意图，调用 `get_recommended_question`。
- 代码：`GetRecommendedQuestionTool.run()`。
- 机制：
  1. 读取 topic/company/difficulty。
  2. 排除已做题。
  3. 调 `multi_recall_recommender.recommend(...)` 多路召回。
  4. 返回候选（Agent 通常展示一道）。

### 2.2 相似题目（换个问法）

- 触发：调用 `find_similar_questions`。
- 代码：`FindSimilarQuestionsTool.run()`。
- 机制（降级链路）：
  1. Neo4j 向量检索 `search_similar`。
  2. 可选 Rerank：`rerank_candidates`。
  3. 过滤 company/difficulty/exclude_id。
  4. 失败降级到 `get_variants`。
  5. 再降级 SQLite 关键词与标签兜底。

### 2.3 智能练习（推荐题 + 随机题）

- 触发：`GET /api/questions/smart-practice`。
- 代码：
  - `backend/main.py` 的 `get_smart_practice_questions`
  - `MultiRecallRecommender.recommend_smart_practice()`
- 机制：
  1. “知识点不足”召回（薄弱点 + 到期复习 + 热门补充）。
  2. 候选放大：`N * SMART_PRACTICE_RECALL_RATIO`。
  3. Rerank 后取 top N。
  4. 再补 M 道随机题。
  5. 返回并标记 `smart_type=recommend/random`。

### 2.4 复习/薄弱点报告

- 触发：`get_mastery_report`。
- 代码：`GetMasteryReportTool.run()`。
- 机制：聚合 `user_tag_mastery`、`study_records`、`episodic_log`，输出薄弱标签、待复习题、建议。

### 2.5 延伸知识点/资源推荐

- 触发：`get_knowledge_recommendation`。
- 代码：`GetKnowledgeRecommendationTool.run()`。
- 机制：
  1. GraphRAG 查概念（题目 -> Concept）。
  2. 查相关概念（`RELATED_TO` 或共现）。
  3. 按概念回题（`get_questions_by_concept`）。
  4. SQLite 资源库返回学习资料。

## 3. Reranker 具体实现

- 服务：`backend/services/rerank_service.py`
- 调用：Ollama `POST /api/rerank`
- 入参：`query + documents + top_n`
- 出参：按 `relevance_score` 排序结果
- 使用点：
  - `find_similar_questions`
  - `multi_recall_recommender.recommend`
  - `recommend_smart_practice`
- 降级：失败时自动回退到原召回分排序，不中断主流程。

## 4. GraphRAG 具体实现

### 4.1 可视化 GraphRAG（前端）

- API：`/api/user/{user_id}/graph-rag`
- 数据构造：`sqlite_service.get_graph_rag_data()`
- 输出：
  - 题库标签共现图
  - 用户做题记录图

### 4.2 检索型 GraphRAG（工具侧）

- 向量检索：`search_similar`
- 概念关系：`get_concepts_by_question` / `get_related_concepts`
- 概念回题：`get_questions_by_concept`
- 标签回题：`get_questions_by_tags`
- 公司回题：`recommend_by_company`

## 5. 关键可调配置

- Rerank：
  - `RERANK_ENABLED`
  - `RERANK_MODEL`
  - `RERANK_OLLAMA_URL`
  - `RERANK_TIMEOUT`
- 检索：
  - `RETRIEVAL_SEARCH_TOP_K`
  - `RETRIEVAL_SCORE_THRESHOLD`
  - `RETRIEVAL_SIMILAR_LIMIT`
- 智能练习：
  - `SMART_PRACTICE_KNOWLEDGE_GAP_COUNT`
  - `SMART_PRACTICE_RANDOM_COUNT`
  - `SMART_PRACTICE_RECALL_RATIO`
  - `SMART_PRACTICE_RERANK_ENABLED`
  - `SMART_PRACTICE_VECTOR_WEIGHT`
  - `SMART_PRACTICE_REVIEW_WEIGHT`
  - `SMART_PRACTICE_POPULAR_WEIGHT`
  - `SMART_PRACTICE_WEAK_TAGS_LIMIT`

## 6. 一句话总结

- 推荐题目 = 多路召回（向量+热门+复习）+ 可选 Rerank。  
- 相似题目 = 先向量，再变体关系，再 SQL 兜底。  
- 智能练习 = 知识点不足 N + 随机 M。  
- GraphRAG = 前端可视化图 + 工具侧概念检索。
