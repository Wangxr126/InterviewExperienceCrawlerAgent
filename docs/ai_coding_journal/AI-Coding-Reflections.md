# AI-Coding 反思记录

更新时间: 2026-05-07

这个文档用于记录我在 AI-Coding 中的复盘、踩坑、判断失误和改进方向。它关注的是“这次为什么有效 / 为什么失败 / 下次怎么更好”。

## 1. 在工程代码能力很强之前，要对AI的coding做逐行review

- review的同时也会加强自己的coding能力
- AI-coding要考虑迭代，所以要对代码十分熟悉，熟悉到修改某个功能能立刻定位到代码仓库位置

## 2. 不要丧失自己的思考能力

- 在使用一个中间件，比如GraphRAG之前要对其基本原理熟悉
- 多做横向的选型对比

## 3. 迭代需求一样一次只做一件事(因为自己的代码能力和工程水平不足以开并行窗口频繁切换注意力)

- 使用SDD开发，能够闭环。
