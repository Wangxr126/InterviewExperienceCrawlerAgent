## 🤖 AI如何知道环境信息？

### 自动识别

AI会通过以下方式自动识别环境：

1. **读取ENVIRONMENT.md**
   - AI会查看项目根目录的环境配置文件
   - 了解需要使用的conda环境

2. **读取README.md**
   - 查看项目文档中的环境说明
   - 了解启动命令

3. **检测启动脚本**
   - 发现start.bat/start.sh
   - 了解标准启动流程

### 手动提醒

如果AI忘记了，你可以：

**简短提醒：**
```
记得用NewCoderAgent环境
```

**详细提醒：**
```
运行Python命令前先激活环境：conda activate NewCoderAgent
```

## 📝 其他项目如何配置？

### 模板：ENVIRONMENT.md

```markdown
# 项目环境配置

## Conda环境
- 环境名称：`你的环境名`
- Python版本：3.x

## 激活命令
\`\`\`bash
conda activate 你的环境名
\`\`\`

## 运行命令
\`\`\`bash
conda activate 你的环境名
python run.py
\`\`\`
```

### 模板：start.bat

```batch
@echo off
call conda activate 你的环境名
python run.py
pause
```

## 🔌 MCP 配置

### MCP 服务列表

项目包含 3 个 MCP 服务，用于扩展 Agent 能力：

| MCP | 功能 | 依赖后端 | 配置位置 |
|-----|------|--------|--------|
| **mcp-content-extractor** | 爬取牛客网/小红书内容 | ✅ 是 | `mcp/mcp-content-extractor/` |
| **mcp-content-fetcher** | 通用网页内容爬取 | ❌ 否 | `mcp/mcp-content-fetcher/` |
| **mcp-image-extractor** | 图片提取与压缩 | ❌ 否 | `mcp/mcp-image-extractor/` |

### Cursor MCP 配置

在 `~/.cursor/mcp.json` 或项目 `.cursor/mcp.json` 中添加：

```json
{
  "mcpServers": {
    "content-extractor": {
      "command": "python",
      "args": ["mcp/mcp-content-extractor/server.py"],
      "cwd": "e:/Agent/AgentProject/wxr_agent",
      "env": {
        "XHS_USER_DATA_DIR": "e:/Agent/AgentProject/wxr_agent/backend/data/xhs_user_data"
      }
    },
    "content-fetcher": {
      "command": "node",
      "args": ["mcp/mcp-content-fetcher/dist/index.js"]
    },
    "image-extractor": {
      "command": "node",
      "args": ["mcp/mcp-image-extractor/dist/index.js"]
    }
  }
}
```

### MCP 初始化

首次使用需要构建 TypeScript MCP：

```bash
# 激活环境
conda activate NewCoderAgent

# 构建 mcp-content-fetcher
cd mcp/mcp-content-fetcher
npm install
npm run build

# 构建 mcp-image-extractor
cd ../mcp-image-extractor
npm install
npm run build

# 返回项目根目录
cd ../..
```
