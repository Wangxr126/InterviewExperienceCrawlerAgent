# 运行环境与 MCP 配置说明

本文档说明 **面经 Agent（wxr_agent）** 在本地运行时的 Conda 环境、启动方式与 MCP 相关配置，便于人与 AI 助手对齐环境。

---

## 1. Python / Conda 环境

| 项 | 说明 |
|----|------|
| 推荐环境名 | `NewCoderAgent` |
| Python | 3.12+（与 `README.md` 一致） |
| 依赖安装 | `pip install -r requirements.txt`，并按 README 安装 spaCy 模型 |

### 启动后端时的两种方式

1. **`python run.py`（Windows 推荐）**  
   根目录 [`run.py`](../run.py) 内写明了目标解释器路径 `CONDA_ENV_PYTHON`。若当前 Python 不是该环境，脚本会用该解释器**重新执行自身**，因此常常**不必**先手动 `conda activate`。若你的机器上 Conda 路径不同，请修改 `run.py` 中的 `CONDA_ENV_PYTHON`。

2. **手动激活后启动**  
   ```bash
   conda activate NewCoderAgent
   python run.py
   ```

### 辅助脚本

- Linux/macOS 可参考 [`backend/scripts/start.sh`](../backend/scripts/start.sh)（需本机已配置好对应 Conda 环境名与路径）。
- 项目根目录**不强制提供** `start.bat`；没有该文件时直接用 `run.py` 即可。

### 给 AI 助手的简短提醒

若需在任何终端命令中统一环境，可说明：「使用 **NewCoderAgent** conda 环境」或「先读 `README.md` / `docs/STARTUP_GUIDE.md`」。

## 3. MCP 服务（可选）

仓库内 MCP 实现位于 `mcp/`，用于扩展抓取与图片能力；后端通过 `.env` 选择本地爬虫或远程抓取、选择 OCR 方式等（见 `CRAWLER_SOURCE`、`OCR_METHOD`、`MCP_*`）。

| 目录 | 作用 |
|------|------|
| `mcp/mcp-content-extractor/` | 牛客/小红书等内容抽取（常依赖后端能力） |
| `mcp/mcp-content-fetcher/` | 通用网页抓取（可独立部署） |
| `mcp/mcp-image-extractor/` | 图片提取与处理 |

### Cursor MCP 配置示例

将 `<项目根>` 换为你的 `wxr_agent` 绝对路径；Windows 下注意 JSON 转义。

```json
{
  "mcpServers": {
    "content-extractor": {
      "command": "python",
      "args": ["mcp/mcp-content-extractor/server.py"],
      "cwd": "<项目根>",
      "env": {
        "XHS_USER_DATA_DIR": "<项目根>/backend/data/xhs_user_data"
      }
    },
    "content-fetcher": {
      "command": "node",
      "args": ["mcp/mcp-content-fetcher/dist/index.js"],
      "cwd": "<项目根>"
    },
    "image-extractor": {
      "command": "node",
      "args": ["mcp/mcp-image-extractor/dist/index.js"],
      "cwd": "<项目根>"
    }
  }
}
```

TypeScript 类 MCP 需先 `npm install && npm run build`（见 [`docs/MCP服务详解.md`](MCP服务详解.md)、[`docs/MCP构建与部署指南.md`](MCP构建与部署指南.md)）。

## 4. 小结

- 环境名：**NewCoderAgent**；启动优先用根目录 **`run.py`**。
- 基础设施：**`docker compose`** 提供 Neo4j + Qdrant；LLM 本地模式需 **Ollama**（若使用）。
- 配置真相源：**项目根 `.env`** + **`backend/config/config.py`**。
