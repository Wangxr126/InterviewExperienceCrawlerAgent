## 3. 开发阶段划分

### Phase 0：基础设施搭建（先决条件）

**目标**：让后续所有 Phase 有可运行的环境基础。

| 任务 | 语言/工具 | 说明 |
|---|---|---|
| Docker Compose 本地环境 | Docker | MySQL + Neo4j + RabbitMQ + Redis 一键启动 |
| MySQL 建表（全量 DDL） | SQL | 2.2 ~ 2.10 中所有表 |
| Neo4j Schema 初始化 | Cypher | Domain / Concept 种子数据，约束和索引 |
| Java 项目骨架 | Spring Boot | 模块划分：api / service / repo / mq / auth |
| Python 项目骨架 | Python | 模块划分：workers / llm / neo4j / utils |
| CI 基础流水线 | GitHub Actions | lint + 单元测试自动触发 |

**验收**：`docker compose up` 后各服务健康，Java 和 Python 项目能跑通 Hello World 接口。

**目标**：上线用户体系基础，能把帖子 URL 变成题目写入 questions 表。

## 6. 开发方式约定

- **SDD（Spec-Driven Development）**：每个模块开发前先写接口/数据结构定义，双方对齐后再实现。
- **TDD**：核心业务逻辑（SM-2 计算、出题策略、相似归组评分）先写单元测试再实现。
- **每个 Phase 对应一个 Git 分支**，Phase 验收后合入 main。
- **TODO 标记**：文档中所有 TODO 在对应 Phase 开始前必须决策，不带 TODO 进入实现。
