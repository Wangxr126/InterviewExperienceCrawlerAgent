## 5. 决策流程

1. 每条 TODO 在标记的"决策时机"前必须有结论。
2. 决策达成后，移到对应大类的"已决策记录"区，记录决策时间。
3. 决策落地的具体修改要回灌到对应 specs 子文档，本表只做索引。
4. 新增 TODO 时同步在本表登记，避免散落。
