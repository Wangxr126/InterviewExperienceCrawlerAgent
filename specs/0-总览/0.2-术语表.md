## 2. 概念区分

### 2.1 链接去重 vs 题目相似归组

| 术语 | 含义 | 关键差异 |
|---|---|---|
| **链接去重** | `source_links.url` 唯一约束，防止同一帖子重复采集 | 硬约束、入库层 |
| **题目相似归组** | 表述相近的不同题目被打上同一 `duplicate_group_id`，**不删除题目**，只在展示层折叠 | 软规则、展示层 |

详见 [3.3 相似归组流水线](../3-后台流水线/3.3-相似归组流水线.md)。

### 2.2 生产链路 vs 实验链路

| 术语 | 含义 | 表 |
|---|---|---|
| **生产链路** | 真实写入题库的抽取流程 | `question_extraction_runs` / `extracted_question_items` |
| **实验链路** | Playground 内部演练，不写入题库 | `extraction_experiments` / `experiment_items` |

二者**完全隔离**，不互相污染。

### 2.3 收藏 / 笔记 / 错题本

| 术语 | 触发方式 | 表 |
|---|---|---|
| **收藏** | 用户主动标记 | `user_favorites` |
| **笔记** | 用户编写正文 | `user_notes` |
| **错题本** | 自动（quality<3 或低分）+ 手动加入 | `user_wrong_questions` |

三表分开，前端三入口同呈现。详见 [2.9](../2-数据模型/2.9-用户与笔记收藏表.md) / [5.6](../5-用户功能/5.6-笔记收藏与错题本.md)。

### 2.4 Concept / Tag / Domain

| 术语 | 含义 | 节点 |
|---|---|---|
| **Domain** | 顶级技术域，手动维护（如 Java、MySQL、RAG） | Neo4j `Domain` |
| **Concept** | 知识概念，LLM 提取（如 IOC、MVCC、HNSW） | Neo4j `Concept` |
| **Tag** | 分类标签（如 "高频"、"简历题"），与 Concept 独立 | Neo4j `Tag` |

详见 [2.3 Neo4j 图谱 Schema](../2-数据模型/2.3-Neo4j图谱Schema.md)。

### 2.5 quality vs total_score

| 术语 | 取值范围 | 来源 |
|---|---|---|
| **quality**（SM-2） | 0~5（整数） | 用户自评（4 档）或 LLM 评分换算 |
| **total_score** | 0~10（连续） | LLM 评分四维加权 |

换算关系见 [5.3 §3.2](../5-用户功能/5.3-闪卡复习.md)。

## 3. 召回相关

| 术语 | 含义 |
|---|---|
| **意图识别** | 判断用户是搜索 / 练习 / 复习 / 出题 |
| **硬过滤** | 按结构化字段（公司/岗位/难度等）裁剪候选 |
| **多路召回** | 向量、标签、图谱、复习队列、关键词等同时召回 |
| **候选融合** | 按 `q_id` 聚合多源候选，合并分数 |
| **重排** | 用 reranker / 规则对融合后的候选重新排序 |
| **多样性控制** | 防止同公司/岗位/标签题目占满结果 |
| **GraphRAG 主路** | 沿 Neo4j `COVERS_CONCEPT` + `RELATED_TO` 扩展 |
| **向量兜底** | Neo4j 向量索引相似搜索，仅在主路结果不足时启用 |
| **recall_sources** | 候选命中的全部召回来源列表 |
| **recommend_reason** | 面向用户的推荐解释短句 |

## 4. Agent / LLM 相关

| 术语 | 含义 |
|---|---|
| **Interviewer Agent** | 主持模拟面试、出题、追问、过渡 |
| **Evaluator Agent** | 评分 Agent，每题结束后产出四维度评分 |
| **AgentScope** | Python 端 Agent 编排框架 |
| **LlamaIndex** | Python 端 RAG / 检索框架 |
| **Callback Manager** | LlamaIndex 内置的钩子机制，用于落审计事件 |
| **Prompt Version** | Prompt 模板的某一版本，旧版本只读不可改 |
| **prompt_hash** | Prompt 内容指纹，用于幂等判断 |
| **rendered_prompt** | 占位符填充后的最终 prompt 快照 |
