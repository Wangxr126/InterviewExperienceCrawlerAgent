## 1. 功能目标

以**闪卡复习**为核心交互（类似墨墨背单词），用用户自评的熟悉程度驱动 SM-2 间隔复习算法，同时接收面试/练习的 LLM 评分作为辅助更新。

核心设计原则：
- **SM-2 质量（quality）由用户自评为主**：用户最清楚自己是真会还是蒙对的。
- **LLM 评分辅助更新**：面试/练习结束后，LLM 分数自动换算 quality 更新 SM-2。
- 答得好的题：拉长复习间隔（不再频繁打扰）。
- 答得差的题：缩短间隔，近期重点复习；自动加入错题本（详见 [5.6](5.6-笔记收藏与错题本.md)）。

## 3. SM-2 算法核心

SM-2 是 SuperMemo 的经典间隔重复算法，适合面试题场景。

### 3.1 关键参数

| 参数 | 初始值 | 说明 |
|---|---|---|
| `ease_factor`（EF） | 2.5 | 难度系数；越低说明题越难记 |
| `interval_days` | 1 | 距下次复习的天数 |
| `repetitions` | 0 | 连续成功回答的次数 |
| `quality` | - | 本次回答质量，0-5 |

> **TODO**：初始 EF=2.5、最低 EF=1.3 为 SM-2 标准值，后续根据实际用户数据验证是否需要针对面试题场景调整。

### 3.2 quality 来源：两条路

**路径 A：闪卡自评（主线）**

用户点击自评按钮 → 直接得到 quality（见第 2.2 节按钮映射）。

**路径 B：面试/练习 LLM 评分（辅线）**

Evaluator Agent 输出的综合分（0-10）自动换算为 quality：

| 综合分（total_score） | SM-2 quality | 含义 |
|---|---|---|
| 9.0 - 10.0 | 5 | 完美回答 |
| 7.0 - 8.9 | 4 | 正确，有些许犹豫 |
| 5.0 - 6.9 | 3 | 正确，但有明显困难 |
| 3.0 - 4.9 | 2 | 错误，但看到答案后能想起 |
| 1.0 - 2.9 | 1 | 错误，记忆模糊 |
| 0 - 0.9 | 0 | 完全不知道/跳过 |

> quality >= 3 为本次"成功复习"；quality < 3 为"失败，重置间隔"。
>
> 路径 A 优先级高于路径 B：如果用户在闪卡中已对同一题自评，当天的 LLM 评分不覆盖闪卡自评结果。

### 3.3 SM-2 更新规则

```python
def sm2_update(ef, interval, repetitions, quality):
    if quality >= 3:  # 成功
        if repetitions == 0:
            new_interval = 1
        elif repetitions == 1:
            new_interval = 6
        else:
            new_interval = round(interval * ef)
        new_repetitions = repetitions + 1
        new_ef = max(1.3, ef + 0.1 - (5 - quality) * (0.08 + (5 - quality) * 0.02))
    else:  # 失败，重置
        new_interval = 1
        new_repetitions = 0
        new_ef = ef  # 难度系数不降低（失败本身已说明问题）

    return new_ef, new_interval, new_repetitions
```

### 3.4 间隔增长示例

假设每次都答 quality=4（良好）：

| 第几次 | interval（天） | 下次复习日期 |
|---|---|---|
| 第 1 次 | 1 | 明天 |
| 第 2 次 | 6 | 6 天后 |
| 第 3 次 | 15 | 15 天后 |
| 第 4 次 | 38 | 38 天后 |
| 第 5 次 | 95 | 3 个月后 |

## 4. 数据流

### 4.1 闪卡复习触发（主线）

```
用户在闪卡界面点击自评按钮
        │
        ▼
quality = 按钮映射值（0/2/3/5）
        │
        ▼
查询 user_question_progress（该 user+q_id）
        │
        ├─ 没有 → 新建记录（EF=2.5, interval=1, reps=0）
        └─ 有   → 读取当前 EF / interval / repetitions
                │
                ▼
        SM-2 更新
                │
                ▼
        写回 user_question_progress（更新 next_review_date）
                │
                ▼
        追加写入 study_review_logs（review_context = 'flashcard'）
                │
                ▼
        若 quality < 3 → 自动加入错题本（[5.6](5.6-笔记收藏与错题本.md)）
```

### 4.2 面试/练习后辅助更新（辅线）

```
Evaluator Agent 输出 total_score
        │
        ▼
score → quality 映射（路径 B）
        │
        ▼
检查当天是否已有闪卡自评记录（review_context = 'flashcard'）
        │
        ├─ 有   → 跳过（不覆盖用户自评）
        └─ 没有 → SM-2 更新 + 写入 study_review_logs（review_context = 'interview' / 'practice'）
                │
                ▼
        若 total_score < 阈值 → 自动加入错题本
```

```

① 待复习题：
   SELECT q_id FROM user_question_progress
   WHERE user_id = ? AND next_review_date <= TODAY()
   ORDER BY next_review_date ASC, ease_factor ASC   ← 越逾期、越难的优先
   LIMIT review_limit   -- TODO: 默认值待定

② 新题推荐（可选，补充当日任务）：
   SELECT q_id FROM questions
   WHERE q_id NOT IN (
     SELECT q_id FROM user_question_progress WHERE user_id = ?
   )
   AND position 关联用户目标岗位
   ORDER BY GraphRAG 概念权重 DESC
   LIMIT new_limit   -- TODO: 默认值待定

③ 写入 user_daily_plans（今日计划）
```
