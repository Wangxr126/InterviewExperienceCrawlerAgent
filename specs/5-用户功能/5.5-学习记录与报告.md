## 2. 薄弱域分析与推荐复习

### 2.1 薄弱域识别（近 30 天数据）

```sql
SELECT
    concept_name,
    AVG(srl.total_score) AS avg_score,
    COUNT(*) AS review_count
FROM study_review_logs srl
JOIN mock_interview_questions miq ON srl.session_question_id = miq.session_question_id
-- miq.covered_concepts_json 展开 → concept_name（应用层处理）
WHERE srl.user_id = :user_id
  AND srl.review_date >= DATE_SUB(CURDATE(), INTERVAL 30 DAY)
GROUP BY concept_name
HAVING review_count >= 2
ORDER BY avg_score ASC
LIMIT 5
```

> **TODO**：薄弱域判定阈值（avg_score < ? 算薄弱）、时间窗口（近 N 天）、最小样本量（review_count >= ?）均待实际数据验证后确定。

### 2.2 薄弱域补题（GraphRAG 召回）

针对薄弱 concept，通过 Neo4j 找到相关题目，加入今日计划：

```cypher
// 薄弱概念：MySQL 事务
MATCH (c:Concept {name: 'MySQL 事务'})-[:RELATED_TO*1..2]-(c2:Concept)
<-[:COVERS_CONCEPT]-(q:Question)
WHERE q.status = 'active'
  AND NOT EXISTS {
    MATCH (q)<-[:for_question]-(p:Progress {user_id: $uid})
    WHERE p.next_review_date > date()   // 未到复习日期的题不重复出
  }
RETURN q.q_id, q.question_text
LIMIT 5
```

> 详细查询模式见 [4.2 GraphRAG 查询模式](../4-检索召回/4.2-GraphRAG查询模式.md)。

## 3. 与其他功能的联动

### 3.1 面试后自动写入

[5.4 模拟面试](5.4-模拟面试与出题.md) 中面试结束后，由 Java 服务批量处理评分结果：

```
mock_interview_evaluations 写入成功
        │
        ▼
Java 消费评分结果（或 Evaluator Agent 回调）
        │
        ▼
批量调用 SM-2 更新接口
        │
        ├─ 更新 user_question_progress
        └─ 追加 study_review_logs
```

### 3.2 复习进度影响出题策略

[5.4](5.4-模拟面试与出题.md) 选题时，过滤近期已做（next_review_date 未到）的题目：

```sql
-- 选题时排除
AND q.q_id NOT IN (
  SELECT q_id FROM user_question_progress
  WHERE user_id = :uid
    AND next_review_date > CURDATE()  -- 还没到复习时间的题，不重复出
)
```

### 3.3 面试报告中展示记忆曲线

[5.4](5.4-模拟面试与出题.md) 报告页，展示当前会话各题的 SM-2 状态变化：

```
题目：请描述 JVM 的内存模型
  本次得分：6.5  →  quality=3（勉强通过）
  复习间隔：1 天 → 6 天（成功，EF 保持 2.5）
  下次复习：2026-05-15
```

## 4. 学习报告页

| 模块 | 展示内容 | 数据来源 |
|---|---|---|
| 学习概览 | 累计复习题数、连续打卡天数、平均得分 | `study_review_logs` 聚合 |
| 周趋势 | 近 7 天每日复习数、平均分曲线 | `study_review_logs.review_date` |
| 月趋势 | 近 30 天复习数 / 平均分 / EF 分布 | 同上 |
| 薄弱域热力图 | 概念维度得分热力图（红=薄弱、绿=熟练） | concept × avg_score |
| 优势域 | 高分概念列表 + 题目数量 | concept × avg_score |
| 题目详情曲线 | 单题历次得分折线、EF 趋势、下次复习倒计时 | `study_review_logs(q_id)` |
| 面试历史 | 历次面试列表（综合分、薄弱域、报告链接） | `mock_interview_reports` |
