## 1. 功能目标

为多用户场景提供个人化的题目沉淀工具，**三个入口同呈现，三张表分开存储**：

| 子功能 | 触发方式 | 数据表 |
|---|---|---|
| **收藏** | 用户主动 ⭐ 标记 | `user_favorites` |
| **笔记** | 用户编写正文 | `user_notes` |
| **错题本** | 自动加入（quality<3 / 低分）+ 手动加入 | `user_wrong_questions` |

> **设计取舍**：三张表分开（参见 [2.9](../2-数据模型/2.9-用户与笔记收藏表.md)）——三种行为语义不同（收藏=记号、笔记=内容、错题=问题诊断），分开比合表更清晰，未来扩展（笔记历史版本、错题克服轨迹）也更友好。

---

## 2. 三大功能详解

### 2.1 收藏

**入口**：题目详情页 / 闪卡 / 列表卡片右上角 ⭐ 按钮。

**特征**：
- 收藏即标记，无正文。
- 一题一收藏（同收藏夹内）。
- 首版只支持默认收藏夹（`folder_name='default'`），但表已支持多收藏夹。

**数据动作**：
- 收藏 → `INSERT user_favorites(user_id, q_id, folder_name='default')`。
- 取消收藏 → `DELETE user_favorites(user_id, q_id, folder_name='default')`。

### 2.2 笔记

**入口**：题目详情页 / 闪卡底部"📝 笔记"按钮。

**特征**：
- 一题一份笔记（覆盖更新）。
- 支持 Markdown。
- 用户可置顶笔记（`is_pinned=1`）。
- 不存历史版本（首版），需要历史时再加 `user_note_versions`。

**数据动作**：
- 编辑保存 → `UPSERT user_notes(user_id, q_id) SET note_text = ?, updated_at = NOW()`。
- 删除 → `DELETE user_notes(user_id, q_id)`。

### 2.3 错题本

**入口**：自动 + 手动两路。

**自动加入触发**：

| 来源 | 触发条件 | source 取值 |
|---|---|---|
| 闪卡复习 | quality < 3 | `auto_flashcard` |
| 模拟面试 | total_score < 阈值（默认 5.0，由 `user_profiles.wrong_score_threshold` 调整） | `auto_interview` |
| 纯出题练习 | total_score < 阈值 | `auto_practice` |

**手动加入**：题目详情页"加错题本"按钮 → `source='manual'`。

**特征**：
- 一题一行（重复触发只更新 `wrong_count` 和 `last_wrong_at`）。
- 用户可标记"已克服"（`is_resolved=1`），从错题本主列表中折叠到"已克服"分区。
- 用户可备注（与笔记不同，错题本备注是"为什么会错"，笔记是"知识总结"）。

**数据动作**：

```python
def mark_wrong(user_id, q_id, source, quality=None, score=None):
    row = db.query("""SELECT * FROM user_wrong_questions
                      WHERE user_id=? AND q_id=?""", user_id, q_id)
    if row:
        db.execute("""UPDATE user_wrong_questions
                      SET wrong_count = wrong_count + 1,
                          last_wrong_at = NOW(),
                          lowest_quality = LEAST(IFNULL(lowest_quality, 5), ?),
                          lowest_score   = LEAST(IFNULL(lowest_score, 10), ?),
                          is_resolved = 0,
                          resolved_at = NULL
                      WHERE user_id=? AND q_id=?""",
                   quality, score, user_id, q_id)
    else:
        db.execute("""INSERT user_wrong_questions(user_id, q_id, source,
                          lowest_quality, lowest_score, wrong_count, last_wrong_at, created_at)
                      VALUES (?, ?, ?, ?, ?, 1, NOW(), NOW())""",
                   user_id, q_id, source, quality, score)
```

## 3. 三入口同呈现

虽然数据分三张表，但前端有一个**统一的"我的题目"页面**，左侧切换三个 tab：

```
┌─────────────────────────────────────────┐
│  我的题目                               │
├─────────────────────────────────────────┤
│  [收藏]  [笔记]  [错题本]                │
├─────────────────────────────────────────┤
│  [筛选] [排序]                          │
├─────────────────────────────────────────┤
│  Q1  Q2  Q3 ...                         │
└─────────────────────────────────────────┘
```

### 3.1 各 tab 的列表展示要素

| Tab | 展示内容 |
|---|---|
| 收藏 | 题干截断 + 收藏时间 + 备注 + 收藏夹标签 |
| 笔记 | 题干截断 + 笔记摘要前 100 字 + 最近编辑时间 + 是否置顶 |
| 错题本 | 题干截断 + 错次数 + 最近答错时间 + 来源标识（闪卡/面试/练习/手动） + 已克服标记 |

### 3.2 各 tab 的筛选项

| Tab | 筛选项 |
|---|---|
| 收藏 | 收藏夹分类（首版只有默认） |
| 笔记 | 是否置顶、按公司 / 岗位筛选 |
| 错题本 | 来源、是否已克服、按概念聚合（薄弱概念热力图） |

### 3.3 联动行为

- 收藏 / 笔记 / 错题本 tab 都支持点击进入题目详情页。
- 详情页同时显示"我已收藏" "我已记笔记" "在错题本中"三个状态标记。

## 4. 错题本的"克服"流程

### 4.1 标记已克服

用户在错题本中点击"已克服"按钮 → `UPDATE user_wrong_questions SET is_resolved=1, resolved_at=NOW()`。

### 4.2 自动重置克服状态

如果题目再次答错（quality<3 或 total_score < 阈值），自动 `is_resolved=0`，重新出现在主错题本列表中。

### 4.3 错题专项练习

错题本提供"开始专项复习"按钮：从错题本中按"未克服优先 + 错次数倒序"出 N 题，进入纯出题练习模式，复用 [5.4 §5](5.4-模拟面试与出题.md) 流程。

## 5. 错题本的统计与可视化

学习报告页（[5.5](5.5-学习记录与报告.md)）展示：
- 错题本总数 / 已克服 / 未克服。
- 错题克服率趋势（周/月）。
- 错题来源分布饼图（闪卡 / 面试 / 练习 / 手动）。
- 错题概念热力图（哪些 Concept 错的最多）。

## 6. 接口骨架

| 接口 | 方法 | 说明 |
|---|---|---|
| `POST /api/me/favorites/{q_id}` | 收藏 | folder_name 可选 |
| `DELETE /api/me/favorites/{q_id}` | 取消收藏 | |
| `GET /api/me/favorites` | 列表 | 我的收藏 |
| `PUT /api/me/notes/{q_id}` | 写笔记 | UPSERT |
| `DELETE /api/me/notes/{q_id}` | 删笔记 | |
| `GET /api/me/notes` | 列表 | 我的笔记 |
| `POST /api/me/wrong/{q_id}` | 加错题本 | source=manual 或自动调用内部接口 |
| `POST /api/me/wrong/{q_id}/resolve` | 标记已克服 | |
| `GET /api/me/wrong` | 列表 | 我的错题本 |
| `POST /api/me/wrong/practice` | 错题专项练习 | 出题接口 |
