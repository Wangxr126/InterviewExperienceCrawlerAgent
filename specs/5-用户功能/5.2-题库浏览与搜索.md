# 5.2 - 题库浏览与搜索

更新时间：2026-05-09  
关联文档：[4.1 召回策略骨架](../4-检索召回/4.1-召回策略骨架.md)、[2.5 相似归组表](../2-数据模型/2.5-相似归组表.md)、[2.3 Neo4j 图谱 Schema](../2-数据模型/2.3-Neo4j图谱Schema.md)、[5.6 笔记收藏与错题本](5.6-笔记收藏与错题本.md)

---

## 1. 功能目标

让用户通过多种入口（关键词搜索、标签 / 概念 / 公司 / 岗位浏览）找到题目，并在题目详情页查看答案、变体题、相关题，进行收藏 / 笔记 / 加错题本等动作。

---

## 2. 入口与页面

| 入口 | 页面 | 说明 |
|---|---|---|
| **题库列表页** | `/questions` | 默认按 `created_at` 倒序，支持筛选 |
| **全局搜索** | `/search?q=...` | 关键词 + 高级筛选 |
| **标签 / 概念页** | `/concepts/{name}` | 单概念聚合，含子概念、相关概念、对应题目 |
| **公司页** | `/companies/{name}` | 公司聚合 |
| **岗位页** | `/positions/{name}` | 岗位聚合 |
| **题目详情页** | `/questions/{q_id}` | 题干 / 答案 / 变体题 / 相关题 / 用户操作 |

---

## 3. 题库列表页

### 3.1 列表展示元素

| 元素 | 数据来源 |
|---|---|
| 题干（截断） | `questions.question_text` |
| 公司 / 岗位 / 难度 / 题型 标签 | `questions.company` / `position` / `difficulty` / `question_type` |
| 标签 chips | `questions.tags_json` |
| "还有 N 道相似题" 折叠提示 | 同 `duplicate_group_id` 题目数 |
| 收藏 / 已收藏标记 | `user_favorites` |
| 已学过标记（last_review_date） | `user_question_progress` |

### 3.2 筛选条件

- 公司多选
- 岗位多选
- 业务线多选
- 难度多选（easy / medium / hard）
- 题型多选
- 来源平台多选
- 仅显示我未做过的（按 `user_question_progress` 过滤）
- 仅显示我已收藏的
- 仅显示我的错题本

### 3.3 排序选项

- 最新入库（默认）
- 按公司 / 岗位
- 按难度
- 按热度（被收藏 / 复习次数累计）

### 3.4 默认折叠规则

按 [2.5 §2](../2-数据模型/2.5-相似归组表.md)：

```sql
WHERE status = 'active'
  AND (duplicate_group_id IS NULL OR is_group_representative = 1)
```

用户可在筛选侧关闭"折叠相似题"，看全量。

## 4. 全局搜索

### 4.1 搜索逻辑

按 [4.1 召回策略骨架 §3](../4-检索召回/4.1-召回策略骨架.md) 中"题库搜索 / 浏览"场景：

1. **关键词命中题干**：直接 SQL `LIKE` / 全文索引（MySQL FULLTEXT 或 ES，按规模决定）。
2. **关键词较短或模糊**：补向量召回（Neo4j 向量索引）。
3. **结构化筛选优先**：先硬过滤再排序。

### 4.2 搜索建议

- 输入时实时联想（基于已有标签、概念名、公司名）。
- 历史搜索词记录（仅本地）。

### 4.3 高级筛选

与列表页筛选一致，可叠加。

## 5. 标签 / 概念页

### 5.1 概念页布局

```
┌─────────────────────────────────────────┐
│  [概念名] IOC                           │
│  描述：控制反转……                       │
├─────────────────────────────────────────┤
│  父概念：Spring → Java                  │
│  子概念：BeanFactory / DI / ApplicationContext │
│  相关概念：AOP / Spring Boot 自动配置    │
├─────────────────────────────────────────┤
│  关联题目（按贡献度排序）                │
│  [Q1] [Q2] [Q3] ...                    │
└─────────────────────────────────────────┘
```

### 5.2 数据来源

- 节点信息：Neo4j `Concept(name=$name)`。
- 父子概念：`BELONGS_TO` 关系。
- 相关概念：`RELATED_TO` 关系。
- 关联题目：`COVERS_CONCEPT` 反向遍历，按 confidence 排序。

详见 [4.2 GraphRAG 查询模式 §4.4](../4-检索召回/4.2-GraphRAG查询模式.md)。

## 6. 公司 / 岗位页

| 元素 | 数据来源 |
|---|---|
| 题目列表 | `WHERE company = $name` 或 `position = $name` |
| 高频概念 Top 10 | Cypher 聚合（见 [4.2 §4.3](../4-检索召回/4.2-GraphRAG查询模式.md)） |
| 难度分布 | SQL `GROUP BY difficulty` |

## 7. 题目详情页

### 7.1 主体布局

```
┌─────────────────────────────────────────┐
│  题干                                   │
│  公司 / 岗位 / 难度 / 标签               │
│  [⭐ 收藏]  [📝 笔记]  [🚫 加错题本]     │
├─────────────────────────────────────────┤
│  参考答案（折叠 / 展开）                 │
├─────────────────────────────────────────┤
│  变体题区（同组 VARIANT_OF）             │
│  Q-similar-1   Q-similar-2 ...          │
├─────────────────────────────────────────┤
│  相关题区（RELATED_TO + COVERS_CONCEPT） │
│  Q-related-1   Q-related-2 ...          │
├─────────────────────────────────────────┤
│  覆盖概念                                │
│  IOC · Spring · BeanFactory             │
├─────────────────────────────────────────┤
│  我的历史                                │
│  上次复习：2026-04-30，得分 7.5          │
│  下次复习：2026-05-15                   │
│  [开始练习这道题]                        │
└─────────────────────────────────────────┘
```

### 7.2 数据来源

| 区域 | 来源 |
|---|---|
| 题干 / 答案 / 标签 | `questions` |
| 用户操作按钮 | `user_favorites` / `user_notes` / `user_wrong_questions` |
| 变体题 | Neo4j `VARIANT_OF` 查询（详见 [3.3 §5](../3-后台流水线/3.3-相似归组流水线.md)） |
| 相关题 | Neo4j `RELATED_TO` + `COVERS_CONCEPT`（详见 [4.2 §4.1 / §4.2](../4-检索召回/4.2-GraphRAG查询模式.md)） |
| 覆盖概念 | Neo4j `COVERS_CONCEPT` |
| 我的历史 | `user_question_progress` + `study_review_logs` |

### 7.3 用户操作

| 操作 | 触发动作 |
|---|---|
| 收藏 | 写 `user_favorites`（详见 [5.6](5.6-笔记收藏与错题本.md)） |
| 笔记 | 弹出编辑器 → 写 `user_notes` |
| 加错题本 | 写 `user_wrong_questions(source='manual')` |
| 报告问题 | 写后台审核队列（题干错 / 答案错） |
| 分享 | 生成短链（实现暂缓，按钮保留） |
| 导出 | 占位"敬请期待" |

## 8. 接口设计骨架

| 接口 | 方法 | 说明 |
|---|---|---|
| `GET /api/questions` | 查询 | 列表 + 筛选 + 排序 + 分页 |
| `GET /api/questions/search` | 查询 | 关键词搜索 |
| `GET /api/questions/{q_id}` | 查询 | 详情 |
| `GET /api/questions/{q_id}/variants` | 查询 | 变体题 |
| `GET /api/questions/{q_id}/related` | 查询 | 相关题 |
| `GET /api/concepts/{name}` | 查询 | 概念页 |
| `GET /api/companies/{name}/questions` | 查询 | 公司聚合 |
| `GET /api/positions/{name}/questions` | 查询 | 岗位聚合 |

详细 API Spec 在实现 Phase 3 时单独细化。

---

## 9. 性能与缓存

| 场景 | 缓存策略 |
|---|---|
| 概念页 | Redis 缓存 5 分钟，概念变化时失效 |
| 热门题列表 | Redis 缓存 10 分钟，新题入库不立即失效 |
| 详情页 | 不缓存（用户态拼接） |
| 搜索 | 关键词热点 Redis 缓存 1 分钟 |
