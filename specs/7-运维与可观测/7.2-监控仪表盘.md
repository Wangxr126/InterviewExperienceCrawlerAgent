## 2. 仪表盘清单（草案）

| 仪表盘 | 内容 | 数据源 |
|---|---|---|
| **服务健康** | 各服务存活、CPU、内存、JVM、Python GC | Prometheus + Actuator |
| **流水线监控** | crawl_tasks 状态分布、抽取成功率、归组进度、向量构建积压 | MySQL 业务表 |
| **队列监控** | 各队列长度、消费速率、DLQ 堆积 | RabbitMQ Management API |
| **LLM 调用** | 各模型 token 用量 / 成本 / 延迟 / 错误率 | `llm_call_audit` |
| **检索质量** | Hit Rate / NDCG / 重排提升 / 兜底比例 | `retrieval_event` + Evaluation |
| **图谱健康** | 节点数、孤立概念、游离 Concept、平均覆盖、RELATED_TO 密度 | 周期任务输出 |
| **学习健康（SM-2）** | 全用户复习量 / 平均 EF / 完成率 / 错题克服率 | `study_review_logs` / `user_question_progress` / `user_wrong_questions` |
| **数据质量** | 各平台采集量 / 接受率 / 拒绝率 / 修正率 | `extracted_question_items` / `experiment_items` |
