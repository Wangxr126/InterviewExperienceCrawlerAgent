# 2.9 - 用户与笔记收藏表

更新时间：2026-05-09  
关联文档：[5.6 笔记收藏与错题本](../5-用户功能/5.6-笔记收藏与错题本.md)、[2.7 学习记录与 SM-2 表](2.7-学习记录与SM2表.md)

---

## 1. 表清单

| 表名 | 职责 |
|---|---|
| `users` | 用户主表（注册 / 登录 / JWT subject） |
| `user_profiles` | 用户画像与静态偏好 |
| `user_favorites` | 收藏记录 |
| `user_notes` | 题目笔记 |
| `user_wrong_questions` | 错题本（自动 + 手动） |

> **设计取舍说明（v2 决策）**：收藏 / 笔记 / 错题本三张表分开设计，不合并为单表 `user_question_marks`。前端三入口同呈现。

---

## 2. `users`

用户身份主表。**所有 user 态表的 `user_id` 外键到此表的 `user_id`。**

| 字段名 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `user_id` | `TEXT` | 主键 | 用户业务主键，UUID |
| `username` | `TEXT` | 非空，唯一 | 登录用户名 |
| `email` | `TEXT` | 可空，唯一 | 邮箱（用于找回密码、第三方关联） |
| `password_hash` | `TEXT` | 非空 | 哈希密码（bcrypt 等） |
| `password_salt` | `TEXT` | 可空 | 盐值（视哈希算法决定是否需要） |
| `display_name` | `TEXT` | 可空 | 昵称 |
| `avatar_url` | `TEXT` | 可空 | 头像 URL |
| `role` | `TEXT` | 非空，默认 `user` | `user` / `admin`（默认只有作者本人为 admin） |
| `status` | `TEXT` | 非空，默认 `active` | `active` / `disabled` / `deleted` |
| `last_login_at` | `DATETIME` | 可空 | 最近登录时间 |
| `created_at` | `DATETIME` | 非空 | 注册时间 |
| `updated_at` | `DATETIME` | 非空 | 最近修改 |

唯一约束：`UNIQUE(username)`、`UNIQUE(email)`（允许 NULL）

---

## 3. `user_profiles`

用户偏好与画像。一对一对应 `users`。

| 字段名 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `user_id` | `TEXT` | 主键，外键 → `users.user_id` | 一对一 |
| `target_position` | `TEXT` | 可空 | 目标岗位（用于推荐） |
| `target_company` | `TEXT` | 可空 | 目标公司 |
| `experience_level` | `TEXT` | 可空 | `intern` / `junior` / `senior` / `staff` / `principal` |
| `preferred_languages` | `TEXT` | 可空 | 偏好语言（JSON 数组） |
| `flashcard_quality_levels` | `TEXT` | 可空 | 自评档位偏好（JSON，覆盖默认 4 档） |
| `daily_review_limit` | `INTEGER` | 可空 | 每日复习上限（覆盖默认） |
| `daily_new_limit` | `INTEGER` | 可空 | 每日新题上限（覆盖默认） |
| `wrong_score_threshold` | `REAL` | 可空 | 错题本自动加入的分数阈值（默认 5.0） |
| `notification_preferences_json` | `TEXT` | 可空 | 通知偏好 |
| `created_at` | `DATETIME` | 非空 | 创建时间 |
| `updated_at` | `DATETIME` | 非空 | 最近修改 |

---

## 4. `user_favorites`

收藏记录。一题最多一行。

| 字段名 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `favorite_id` | `TEXT` | 主键 | 收藏记录主键 |
| `user_id` | `TEXT` | 非空，外键 → `users.user_id` | 用户 |
| `q_id` | `TEXT` | 非空，外键 → `questions.q_id` | 题目 |
| `folder_name` | `TEXT` | 可空，默认 `default` | 收藏夹分类（首版只支持默认夹，预留分类能力） |
| `note_brief` | `TEXT` | 可空 | 收藏时的简短备注（不同于完整笔记） |
| `created_at` | `DATETIME` | 非空 | 收藏时间 |

唯一约束：`UNIQUE(user_id, q_id, folder_name)`（同一题在同一收藏夹内只能收藏一次）。

---

## 5. `user_notes`

题目笔记。每条笔记保留多次编辑覆盖（不存历史版本，需历史可后续加 `user_note_versions`）。

| 字段名 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `note_id` | `TEXT` | 主键 | 笔记主键 |
| `user_id` | `TEXT` | 非空，外键 → `users.user_id` | 用户 |
| `q_id` | `TEXT` | 非空，外键 → `questions.q_id` | 题目 |
| `note_text` | `TEXT` | 非空 | 笔记正文（Markdown） |
| `is_pinned` | `INTEGER` | 非空，默认 0 | 是否置顶（笔记列表用） |
| `created_at` | `DATETIME` | 非空 | 首次创建时间 |
| `updated_at` | `DATETIME` | 非空 | 最近编辑时间 |

唯一约束：`UNIQUE(user_id, q_id)`（一题一份笔记）。

> 若后续需要"历史版本"，再新增 `user_note_versions` 表，每次编辑追加一行；当前不前置。

---

## 6. `user_wrong_questions`

错题本。**支持自动加入（quality<3 / total_score < 阈值）和手动加入。**

| 字段名 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `wrong_id` | `TEXT` | 主键 | 错题本记录主键 |
| `user_id` | `TEXT` | 非空，外键 → `users.user_id` | 用户 |
| `q_id` | `TEXT` | 非空，外键 → `questions.q_id` | 题目 |
| `source` | `TEXT` | 非空 | 加入来源：`auto_flashcard` / `auto_interview` / `auto_practice` / `manual` |
| `lowest_quality` | `INTEGER` | 可空 | 触发加入时的 SM-2 quality（自动加入用） |
| `lowest_score` | `REAL` | 可空 | 触发加入时的 total_score（自动加入用） |
| `wrong_count` | `INTEGER` | 非空，默认 1 | 该题被错的次数（同 q_id 再次答错时累加，不新建行） |
| `last_wrong_at` | `DATETIME` | 非空 | 最近一次答错时间 |
| `is_resolved` | `INTEGER` | 非空，默认 0 | 是否已"克服"（用户主动标记） |
| `resolved_at` | `DATETIME` | 可空 | 克服时间 |
| `user_remark` | `TEXT` | 可空 | 用户备注（可能与 user_notes 重复，但语义不同） |
| `created_at` | `DATETIME` | 非空 | 首次加入时间 |

唯一约束：`UNIQUE(user_id, q_id)`（一题一行，重复触发只更新 `wrong_count` 和 `last_wrong_at`）。

## 7. 关系

```
users (1) ── (1) user_profiles
users (1) ─< (N) user_favorites      >─ (1) questions
users (1) ─< (N) user_notes          >─ (1) questions
users (1) ─< (N) user_wrong_questions >─ (1) questions
users (1) ─< (N) user_question_progress >─ (1) questions    (详见 2.7)
users (1) ─< (N) study_review_logs   >─ (1) questions       (详见 2.7)
users (1) ─< (N) mock_interview_sessions                    (详见 2.6)
users (1) ─< (N) source_links (submitted_by)                (详见 2.8)
```

**所有 user 态表的 user_id 都外键到 `users.user_id`，且 `NOT NULL`**——这是用户系统提前到 Phase 1 的硬约束。

## 8. 索引建议

| 表 | 索引 | 用途 |
|---|---|---|
| `users` | `UNIQUE(username)` / `UNIQUE(email)` | 登录、找回密码 |
| `user_profiles` | 主键即可 | — |
| `user_favorites` | `(user_id, created_at DESC)` | 我的收藏列表 |
| `user_favorites` | `UNIQUE(user_id, q_id, folder_name)` | 防重 |
| `user_notes` | `(user_id, updated_at DESC)` | 我的笔记列表 |
| `user_notes` | `UNIQUE(user_id, q_id)` | 一题一份 |
| `user_wrong_questions` | `(user_id, last_wrong_at DESC)` | 错题本列表 |
| `user_wrong_questions` | `(user_id, is_resolved)` | 区分未克服 / 已克服 |
| `user_wrong_questions` | `UNIQUE(user_id, q_id)` | 一题一行 |

---

## 9. 安全与隐私

- 所有 user 态查询接口都强制按 `user_id` 过滤，禁止 cross-user 访问。
- `password_hash` 不能在任何 API 返回。
- 删除用户：保留 `users` 行，置 `status = 'deleted'`，相关 user 态表保留以维持引用完整性，前端不展示。
- 第三方 OAuth（GitHub / 飞书）后续接入时，新增 `user_oauth_bindings` 表，不污染 `users` 主表。
