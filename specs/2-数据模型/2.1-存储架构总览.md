## 1. 存储分层

| 层 | 技术 | 管理方 | 职责 |
|---|---|---|---|
| 关系型主库 | MySQL | Java Spring Boot | 所有业务主表：题库、用户、会话、任务、抽取、向量投影、笔记/收藏/错题本等 |
| 图数据库 | Neo4j | Python LlamaIndex / Java Driver | 知识图谱、相似归组关系、向量检索 |
| 缓存 / 限流 | Redis | Java Spring Boot | 会话、热点、限流、分布式锁 |
| 向量库（按需） | Qdrant | Python LlamaIndex | 大规模向量检索（规模瓶颈时引入） |
| 链路追踪 | OpenTelemetry + Jaeger/Loki | 运维 | 全链路 Trace 和日志聚合 |

> 中间件选型理由见 [1.3 中间件选型](../1-技术选型/1.3-中间件选型.md)。

## 3. Neo4j 节点 / 关系（[2.3 Neo4j 图谱 Schema](2.3-Neo4j图谱Schema.md)）

| 节点 | 关系（指向） | 一句话职责 |
|---|---|---|
| `Domain` | — | 顶级技术域，手动维护 |
| `Concept` | `BELONGS_TO` / `RELATED_TO` / `PREREQUISITE_OF` | 知识概念，LLM 提取 |
| `Question` | `HAS_TAG` / `FROM_COMPANY` / `FOR_POSITION` / `COVERS_CONCEPT` / `VARIANT_OF` | 题目节点，含向量 |
| `Tag` / `Company` / `Position` | — | 分类节点 |

向量索引 `question-embeddings` / `concept-embeddings` 也在 Neo4j 内。

## 4. 存储分工总览（与各链路的对应）

| 链路 | 主要存储 |
|---|---|
| 采集与抓取 | MySQL：`source_links`、`crawl_tasks`、`crawl_artifacts` |
| LLM 抽取 | MySQL：`question_extraction_runs`、`extracted_question_items` |
| 题库入库 | MySQL：`questions`；Neo4j：`Question` 节点及关系 |
| 向量构建 | MySQL：`question_vectors`（元数据）；Neo4j：`Question.embedding` |
| 题库浏览 | MySQL 主查询；Neo4j 相似归组补充 |
| 练习与复习 | MySQL：`study_review_logs`、`user_question_progress`、`mock_interview_*` |
| GraphRAG 问答 | Neo4j：多跳图遍历 |
| Prompt 管理 | MySQL：`prompt_templates`、`prompt_versions` |
| Playground 实验 | MySQL：`extraction_experiments`、`experiment_items`、`item_corrections` |
| 检索审计 | MySQL：`retrieval_event` |
| 相似归组（展示） | MySQL：归组管理表；Neo4j：`VARIANT_OF` 关系 |
| 笔记/收藏/错题本 | MySQL：`user_notes` / `user_favorites` / `user_wrong_questions` |
| 用户与鉴权 | MySQL：`users` / `user_profiles`；Redis：会话缓存 |

## 5. 关键设计原则

1. **主键全部由应用层生成**（UUID / ULID），不使用自增 ID 做业务标识。
2. **语义字段不设默认值**：识别不到就留空，不猜。
3. **`questions` 表只存当前快照**，不存历史版本和中间过程。
4. **唯一去重只在 `source_links.url`**，题目主表不承担去重职责。
5. **向量层是派生层**，不是事实源，可以重建。
6. **生产抽取链路和实验链路完全隔离**，`extraction_experiments` 不写入 `question_extraction_runs`。

## 6. Qdrant 引入后的分工调整

| 职责 | 引入前 | 引入后 |
|---|---|---|
| 向量检索 | Neo4j | Qdrant（ANN 更快） |
| 图谱关系存储 | Neo4j | Neo4j（不变） |
| GraphRAG 扩展 | Neo4j | Neo4j（不变） |

LlamaIndex 有原生 Qdrant 集成，切换成本低，只需修改 Retriever 配置。
