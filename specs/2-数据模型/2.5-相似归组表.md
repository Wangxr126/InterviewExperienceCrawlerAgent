## 2. `questions` 表字段扩展

在 [2.2 题库主表设计](2.2-题库主表设计.md) 原有字段基础上，**仅展示层使用**的归组字段：

| 字段名 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `duplicate_group_id` | `TEXT` | 可空 | 所属归组 ID；NULL 表示未归组或唯一题（已在 2.2 中定义） |
| `is_group_representative` | `INTEGER` | 非空，默认 0 | 是否为代表题（浏览过滤用） |
| `dedup_status` | `TEXT` | 非空，默认 `unprocessed` | 归组任务处理状态：`unprocessed` / `no_match` / `grouped` / `review_pending` |

**浏览 API 的核心过滤逻辑**：

```sql
SELECT * FROM questions
WHERE status = 'active'
  AND (duplicate_group_id IS NULL OR is_group_representative = 1)
-- 展示：未归组的题 + 每组的代表题
```

## 5. `dedup_review_queue`

| 字段名 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `review_id` | `TEXT` | 主键 | 审核记录主键 |
| `q_id_a` | `TEXT` | 非空，外键 | 题目 A |
| `q_id_b` | `TEXT` | 非空，外键 | 题目 B |
| `composite_score` | `REAL` | 非空 | 综合相似分 |
| `vector_sim` | `REAL` | 可空 | 向量分量 |
| `concept_jaccard` | `REAL` | 可空 | 概念 Jaccard 分量 |
| `shared_concepts` | `TEXT` | 可空 | 共享概念名称（JSON 数组，审核时展示） |
| `shared_tags` | `TEXT` | 可空 | 共享标签（JSON 数组） |
| `review_status` | `TEXT` | 非空，默认 `pending` | `pending` / `same_group` / `different` / `ignored` |
| `reviewed_at` | `DATETIME` | 可空 | 审核时间 |
| `review_note` | `TEXT` | 可空 | 审核说明 |
| `created_at` | `DATETIME` | 非空 | 候选对生成时间 |

唯一约束：`(q_id_a, q_id_b)`，约定 `q_id_a < q_id_b`（字典序）。

## 6. Neo4j 中的归组关系

归组结果同时写入 Neo4j（详见 [2.3 Neo4j 图谱 Schema](2.3-Neo4j图谱Schema.md)）：

| 关系 | 含义 | 用途 |
|---|---|---|
| `(Question)-[:VARIANT_OF]->(Question)` | 变体题关系（同一道题的不同说法） | 展示层折叠；GraphRAG 扩展 |
| `(Question)-[:RELATED_TO]->(Question)` | 相关但不是变体 | 详情页"相关题推荐" |

`VARIANT_OF` 关系属性：

```
VARIANT_OF {
  composite_score: 0.91,     // 综合相似分
  vector_sim: 0.85,          // 向量相似分量
  concept_jaccard: 0.67,     // 概念 Jaccard 分量
  method: "auto_hybrid",     // auto_hybrid / manual
  created_at: "..."
}
```

## 7. 索引建议

| 表 | 索引 | 用途 |
|---|---|---|
| `questions` | `(duplicate_group_id, is_group_representative)` | 浏览过滤 |
| `questions` | `(dedup_status)` | 归组 worker 扫描 |
| `question_group_members` | `(group_id, role)` | 查代表题 / 全组成员 |
| `question_group_members` | `(q_id)` 唯一 | 一题一组 |
| `dedup_review_queue` | `(review_status, composite_score DESC)` | 审核队列展示 |
