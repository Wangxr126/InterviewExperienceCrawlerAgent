# 2.4 - Prompt 版本与 Playground 表

更新时间：2026-05-09  
关联文档：[5.1 Prompt-Playground 功能](../5-用户功能/5.1-Prompt-Playground功能.md)、[2.2 题库主表设计](2.2-题库主表设计.md)

---

## 1. 表清单

| 表名 | 职责 |
|---|---|
| `prompt_templates` | Prompt 模板的"类别"定义层 |
| `prompt_versions` | 版本化的 Prompt 内容 + 模型配置（只增不改） |
| `extraction_experiments` | Playground 实验运行记录 |
| `experiment_items` | 实验产出的题目明细 |
| `item_corrections` | 实验题目的人工修正记录 |

---

## 2. `prompt_templates`

Prompt 模板的"类别"定义层，一个模板对应多个版本。

| 字段名 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `template_id` | `TEXT` | 主键 | 模板业务主键 |
| `name` | `TEXT` | 非空，唯一 | 模板名称，如 `question_extraction_v1` |
| `template_type` | `TEXT` | 非空 | 用途分类：`question_extraction` / `answer_refinement` / `classification` / `interviewer` / `evaluator` |
| `description` | `TEXT` | 可空 | 模板用途说明 |
| `is_active` | `INTEGER` | 非空，默认 1 | 是否启用（0=归档，1=活跃） |
| `created_at` | `DATETIME` | 非空 | 创建时间 |
| `updated_at` | `DATETIME` | 非空 | 最近修改时间 |

---

## 3. `prompt_versions`

每次保存 prompt 都产生一条记录，旧版本只读。

| 字段名 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `version_id` | `TEXT` | 主键 | 版本业务主键 |
| `template_id` | `TEXT` | 非空，外键 | 归属的模板 |
| `version_number` | `INTEGER` | 非空 | 版本号，同一模板自增（1, 2, 3...） |
| `prompt_content` | `TEXT` | 非空 | Prompt 正文，包含占位符（如 `{page_text}`、`{company}`） |
| `system_prompt` | `TEXT` | 可空 | System prompt（如有），与 user prompt 分开存 |
| `output_schema_json` | `TEXT` | 可空 | 期望的输出 JSON Schema，用于校验 LLM 输出格式 |
| `model_provider` | `TEXT` | 非空 | 绑定的模型供应商，如 `openai` / `deepseek` / `anthropic` |
| `model_name` | `TEXT` | 非空 | 具体模型名 |
| `llm_params_json` | `TEXT` | 可空 | 模型参数：temperature、top_p、max_tokens 等 |
| `change_note` | `TEXT` | 可空 | 本次修改说明（类似 git commit message） |
| `is_default` | `INTEGER` | 非空，默认 0 | 是否为当前生产默认版本（同一模板只能有一个为 1） |
| `prompt_hash` | `TEXT` | 非空 | `prompt_content + system_prompt` 的内容指纹 |
| `created_at` | `DATETIME` | 非空 | 创建时间（即版本保存时间） |

> **设计约束**：`prompt_versions` 只增不改，一旦创建就不可修改 `prompt_content`。修改 prompt 等于创建新版本，版本号自增。

---

## 4. `extraction_experiments`

一次 Playground 实验运行记录。

| 字段名 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `experiment_id` | `TEXT` | 主键 | 实验业务主键 |
| `version_id` | `TEXT` | 非空，外键 | 使用的 prompt 版本 |
| `artifact_id` | `TEXT` | 非空，外键 | 使用的抓取产物（`crawl_artifacts`），即输入底料 |
| `source_link_id` | `TEXT` | 非空，外键 | 来源链接，便于回溯和筛选 |
| `override_model_provider` | `TEXT` | 可空 | 覆盖 prompt_version 绑定的模型供应商（Playground 临时切换用） |
| `override_model_name` | `TEXT` | 可空 | 覆盖模型名 |
| `override_llm_params_json` | `TEXT` | 可空 | 覆盖模型参数 |
| `effective_model_provider` | `TEXT` | 非空 | 实际生效的模型供应商（override 或 version 中的值） |
| `effective_model_name` | `TEXT` | 非空 | 实际生效的模型名 |
| `rendered_prompt` | `TEXT` | 可空 | 占位符填充后的最终 prompt 快照（用于回放） |
| `raw_output` | `TEXT` | 可空 | LLM 的原始输出 |
| `output_parse_status` | `TEXT` | 非空 | 输出解析状态：`success` / `parse_failed` / `schema_mismatch` |
| `run_status` | `TEXT` | 非空 | 运行状态：`pending` / `running` / `succeeded` / `failed` |
| `triggered_by` | `TEXT` | 非空 | 触发方式：`manual`（前端手动）/ `auto`（批量测试） |
| `token_input` | `INTEGER` | 可空 | 输入 token 数 |
| `token_output` | `INTEGER` | 可空 | 输出 token 数 |
| `cost_usd` | `REAL` | 可空 | 本次调用费用估算（美元） |
| `latency_ms` | `INTEGER` | 可空 | 端到端耗时（毫秒） |
| `error_msg` | `TEXT` | 可空 | 失败原因 |
| `started_at` | `DATETIME` | 非空 | 开始时间 |
| `finished_at` | `DATETIME` | 可空 | 结束时间 |
| `created_at` | `DATETIME` | 非空 | 创建时间 |

---

## 5. `experiment_items`

一次实验产出的题目明细，结构与 `extracted_question_items`（详见 [2.2](2.2-题库主表设计.md)）类似，但独立存放。

| 字段名 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `exp_item_id` | `TEXT` | 主键 | 实验题目主键 |
| `experiment_id` | `TEXT` | 非空，外键 | 关联实验 |
| `item_order` | `INTEGER` | 非空 | 题目在本次输出中的顺序 |
| `question_text` | `TEXT` | 非空 | 抽取的题干 |
| `answer_text` | `TEXT` | 可空 | 抽取的答案 |
| `tags_json` | `TEXT` | 可空 | 抽取的标签（JSON 数组） |
| `company` | `TEXT` | 可空 | 抽取的公司信息 |
| `position` | `TEXT` | 可空 | 抽取的岗位信息 |
| `difficulty` | `TEXT` | 可空 | 抽取的难度 |
| `question_type` | `TEXT` | 可空 | 抽取的题型 |
| `confidence` | `REAL` | 可空 | 抽取置信度 |
| `review_status` | `TEXT` | 非空，默认 `pending` | 人工审核状态：`pending` / `accepted` / `rejected` / `corrected` |
| `promoted_q_id` | `TEXT` | 可空 | 若已推送到题库，记录对应的 `q_id` |
| `created_at` | `DATETIME` | 非空 | 创建时间 |

---

## 6. `item_corrections`

对实验题目的人工修正记录，每次修正产生一条，保留完整修正历史。

| 字段名 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `correction_id` | `TEXT` | 主键 | 修正记录主键 |
| `exp_item_id` | `TEXT` | 非空，外键 | 关联的实验题目 |
| `experiment_id` | `TEXT` | 非空，外键 | 关联的实验（冗余，便于查询） |
| `version_id` | `TEXT` | 非空，外键 | 关联的 prompt 版本（方便统计"哪个版本需要修正最多"） |
| `corrected_question_text` | `TEXT` | 可空 | 修正后的题干（空表示未修改） |
| `corrected_answer_text` | `TEXT` | 可空 | 修正后的答案（空表示未修改） |
| `corrected_tags_json` | `TEXT` | 可空 | 修正后的标签（空表示未修改） |
| `corrected_difficulty` | `TEXT` | 可空 | 修正后的难度 |
| `corrected_question_type` | `TEXT` | 可空 | 修正后的题型 |
| `action` | `TEXT` | 非空 | 操作类型：`accept` / `reject` / `edit` |
| `reject_reason` | `TEXT` | 可空 | 拒绝时的理由 |
| `correction_note` | `TEXT` | 可空 | 修正说明，例如"答案不完整"、"题型分类错误" |
| `corrected_at` | `DATETIME` | 非空 | 修正时间 |

---

## 7. 与生产链路的对接

| 现有表 | 与本组表的关系 |
|---|---|
| `crawl_artifacts` | 实验的"输入底料"来源，artifact 可被多次实验复用 |
| `question_extraction_runs` | **生产链路专用**，与实验链路完全分离，不混用 |
| `extracted_question_items` | **生产链路专用**，实验结果不写入此表 |
| `questions` | 实验结果可以"推送"到此表（`promoted_q_id` 关联） |
| `prompt_versions.version_id` | 生产链路 `question_extraction_runs.prompt_version` 字段建议改为引用此表的 `version_id`，实现统一管理 |

---

## 8. 建表顺序

```
1. prompt_templates
2. prompt_versions
3. extraction_experiments
4. experiment_items
5. item_corrections
```

## 9. 索引建议

| 表 | 索引 | 用途 |
|---|---|---|
| `prompt_versions` | `(template_id, version_number)` 唯一 | 版本号唯一 |
| `prompt_versions` | `(template_id, is_default)` 部分索引 | 加速查询默认版本 |
| `extraction_experiments` | `(version_id, started_at)` | 同版本实验列表 |
| `extraction_experiments` | `(source_link_id, started_at)` | 同帖子实验对比 |
| `experiment_items` | `(experiment_id, item_order)` | 按实验聚合 |
| `item_corrections` | `(exp_item_id, corrected_at)` | 修正历史 |
