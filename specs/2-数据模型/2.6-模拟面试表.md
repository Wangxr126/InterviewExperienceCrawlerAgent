# 2.6 - 模拟面试表

更新时间：2026-05-09  
关联文档：[5.4 模拟面试与出题](../5-用户功能/5.4-模拟面试与出题.md)、[2.7 学习记录与SM2表](2.7-学习记录与SM2表.md)

---

## 1. 表清单

| 表名 | 职责 | 是否首版必需 |
|---|---|---|
| `mock_interview_sessions` | 面试会话主表 | 必需 |
| `mock_interview_questions` | 会话内题目快照与执行状态 | 必需 |
| `mock_interview_turns` | 多轮对话记录（追问、用户回答） | 必需 |
| `mock_interview_evaluations` | 单题评分结果 | 必需 |
| `mock_interview_reports` | 面试结束报告 | 必需 |

---

## 2. `mock_interview_sessions`

| 字段名 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `session_id` | `TEXT` | 主键 | 面试会话主键 |
| `user_id` | `TEXT` | 非空，外键 | 用户 |
| `mode` | `TEXT` | 非空 | 模式：`interview` / `practice` |
| `position` | `TEXT` | 非空 | 岗位（必选配置项） |
| `company` | `TEXT` | 可空 | 目标公司 |
| `round_type` | `TEXT` | 可空 | 面试轮次 |
| `difficulty` | `TEXT` | 可空 | 难度偏好 |
| `domains_json` | `TEXT` | 可空 | 用户选择的知识领域（JSON 数组） |
| `question_count` | `INTEGER` | 非空 | 题目总数 |
| `time_limit_min` | `INTEGER` | 可空 | 时间限制（分钟），NULL = 不限 |
| `status` | `TEXT` | 非空，默认 `draft` | `draft` / `in_progress` / `paused` / `completed` / `reported` |
| `overall_score` | `REAL` | 可空 | 综合分（completed 后填写） |
| `interviewer_style` | `TEXT` | 可空 | 面试官风格：`standard` / `strict` / `encouraging` |
| `started_at` | `DATETIME` | 可空 | 开始时间 |
| `completed_at` | `DATETIME` | 可空 | 结束时间 |
| `created_at` | `DATETIME` | 非空 | 创建时间 |
| `updated_at` | `DATETIME` | 非空 | 最近修改时间 |

---

## 3. `mock_interview_questions`

| 字段名 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `session_question_id` | `TEXT` | 主键 | 会话题目主键 |
| `session_id` | `TEXT` | 非空，外键 | 所属会话 |
| `q_id` | `TEXT` | 可空，外键 | 题库题目 ID；LLM 生成题为空 |
| `display_order` | `INTEGER` | 非空 | 本场面试中的出题顺序 |
| `question_text` | `TEXT` | 非空 | 题干快照（防止题库更新影响历史记录） |
| `reference_answer` | `TEXT` | 可空 | 参考答案快照 |
| `question_source` | `TEXT` | 非空 | `question_bank` / `llm_generated` |
| `covered_concepts_json` | `TEXT` | 可空 | 题目覆盖的概念名称（JSON 数组，用于报告分析） |
| `difficulty` | `TEXT` | 可空 | 题目难度 |
| `status` | `TEXT` | 非空，默认 `pending` | `pending` / `in_progress` / `evaluated` / `skipped` |
| `contributed_to_bank` | `INTEGER` | 非空，默认 0 | LLM 生成题是否已贡献到题库 |
| `created_at` | `DATETIME` | 非空 | 创建时间 |

---

## 4. `mock_interview_turns`

| 字段名 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `turn_id` | `TEXT` | 主键 | 轮次主键 |
| `session_id` | `TEXT` | 非空，外键 | 所属会话 |
| `session_question_id` | `TEXT` | 非空，外键 | 所属题目 |
| `turn_order` | `INTEGER` | 非空 | 该题目内的轮次顺序 |

| `content` | `TEXT` | 非空 | 消息内容 |
| `created_at` | `DATETIME` | 非空 | 消息时间 |

---

## 5. `mock_interview_evaluations`

| 字段名 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `eval_id` | `TEXT` | 主键 | 评分记录主键 |
| `session_id` | `TEXT` | 非空，外键 | 所属会话 |
| `session_question_id` | `TEXT` | 非空，外键，唯一 | 所属题目（一题一份评分） |
| `score_correctness` | `REAL` | 可空 | 正确性（0-10） |
| `score_completeness` | `REAL` | 可空 | 完整性（0-10） |
| `score_depth` | `REAL` | 可空 | 深度（0-10） |
| `score_expression` | `REAL` | 可空 | 表达（0-10） |
| `total_score` | `REAL` | 可空 | 综合分（0-10） |
| `missed_key_points_json` | `TEXT` | 可空 | 遗漏的关键点（JSON 数组） |
| `feedback` | `TEXT` | 可空 | 评价反馈文本 |
| `model_provider` | `TEXT` | 非空 | 评分使用的模型供应商 |
| `model_name` | `TEXT` | 非空 | 评分使用的模型名 |
| `prompt_version` | `TEXT` | 可空 | 评分 prompt 版本（关联 [2.4 Prompt版本与Playground表](2.4-Prompt版本与Playground表.md) `prompt_versions.version_id`） |
| `created_at` | `DATETIME` | 非空 | 评分时间 |

## 6. `mock_interview_reports`

| 字段名 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `report_id` | `TEXT` | 主键 | 报告主键 |
| `session_id` | `TEXT` | 非空，外键，唯一 | 所属会话（一场面试一份报告） |
| `overall_score` | `REAL` | 非空 | 总分 |
| `dimension_avg_json` | `TEXT` | 可空 | 四维度平均分（JSON） |
| `domain_scores_json` | `TEXT` | 可空 | 各知识域得分（JSON，key=concept/domain，value=avg_score） |
| `strong_areas_json` | `TEXT` | 可空 | 优势概念域（JSON 数组） |
| `weak_areas_json` | `TEXT` | 可空 | 薄弱概念域（JSON 数组） |
| `recommendations_json` | `TEXT` | 可空 | 推荐复习方向（JSON 数组，含 concept + question_count） |
| `interviewer_summary` | `TEXT` | 可空 | Interviewer Agent 生成的整体评语 |
| `created_at` | `DATETIME` | 非空 | 报告生成时间 |

---

## 7. 关系与索引

| 关系 | 约束 |
|---|---|
| `mock_interview_sessions.user_id` → 用户表 | 非空 |
| `mock_interview_sessions` → `mock_interview_questions` | 一会话多题目 |
| `mock_interview_questions` → `mock_interview_turns` | 一题多轮 |
| `mock_interview_questions` → `mock_interview_evaluations` | 一题一评分 |
| `mock_interview_sessions` → `mock_interview_reports` | 一会话一报告 |
| `mock_interview_questions.q_id` → `questions.q_id` | 可空（LLM 生成题为空） |

| 表 | 索引 | 用途 |
|---|---|---|
| `mock_interview_sessions` | `(user_id, status, started_at)` | 查询用户面试历史 |
| `mock_interview_questions` | `(session_id, display_order)` | 按出题顺序展示 |
| `mock_interview_turns` | `(session_question_id, turn_order)` | 还原对话顺序 |
| `mock_interview_evaluations` | `(session_id)` | 报告生成时聚合 |
