# 2.7 - 学习记录与 SM-2 表

更新时间：2026-05-09  
关联文档：[5.3 闪卡复习](../5-用户功能/5.3-闪卡复习.md)、[5.5 学习记录与报告](../5-用户功能/5.5-学习记录与报告.md)、[2.6 模拟面试表](2.6-模拟面试表.md)

---

## 1. 表清单

| 表名 | 职责 |
|---|---|
| `user_question_progress` | 用户每道题的当前 SM-2 状态（每对 user+question 一行） |
| `study_review_logs` | 答题历史日志（只追加） |
| `user_daily_plans` | 每日复习计划 |

---

## 2. `user_question_progress`

记录每个用户对每道题的当前 SM-2 状态（每对 user+question 仅一行，更新覆盖）。

| 字段名 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `progress_id` | `TEXT` | 主键 | 记录主键 |
| `user_id` | `TEXT` | 非空，外键 | 用户 |
| `q_id` | `TEXT` | 非空，外键 | 题目 |
| `ease_factor` | `REAL` | 非空，默认 2.5 | SM-2 难度系数（最低 1.3） |
| `interval_days` | `INTEGER` | 非空，默认 1 | 距下次复习的天数 |
| `repetitions` | `INTEGER` | 非空，默认 0 | 连续成功次数 |
| `last_quality` | `INTEGER` | 可空 | 上次回答质量（0-5） |
| `last_score` | `REAL` | 可空 | 上次综合分（0-10，展示用） |
| `last_review_date` | `DATE` | 可空 | 上次复习日期 |
| `next_review_date` | `DATE` | 可空 | 下次应复习日期（NULL 表示从未学过） |
| `total_reviews` | `INTEGER` | 非空，默认 0 | 累计复习次数 |
| `created_at` | `DATETIME` | 非空 | 首次遇见该题时间 |
| `updated_at` | `DATETIME` | 非空 | 最近更新时间 |

索引：`UNIQUE(user_id, q_id)`、`INDEX(user_id, next_review_date)`

---

## 3. `study_review_logs`

不可变的答题历史日志（只追加，不更新）。

| 字段名 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `log_id` | `TEXT` | 主键 | 日志主键 |
| `user_id` | `TEXT` | 非空，外键 | 用户 |
| `q_id` | `TEXT` | 非空，外键 | 题目 |
| `session_id` | `TEXT` | 可空，外键 | 来源会话（面试/练习） |
| `session_question_id` | `TEXT` | 可空，外键 | 来源会话题目记录 |
| `review_context` | `TEXT` | 非空 | 答题来源：`flashcard` / `interview` / `practice` |
| `review_date` | `DATE` | 非空 | 答题日期 |
| `quality` | `INTEGER` | 非空 | SM-2 质量值（0-5） |
| `score_correctness` | `REAL` | 可空 | 正确性分（0-10） |
| `score_completeness` | `REAL` | 可空 | 完整性分（0-10） |
| `score_depth` | `REAL` | 可空 | 深度分（0-10） |
| `score_expression` | `REAL` | 可空 | 表达分（0-10） |
| `total_score` | `REAL` | 非空 | 综合分（0-10） |
| `ef_before` | `REAL` | 非空 | 本次更新前的 ease_factor |
| `ef_after` | `REAL` | 非空 | 本次更新后的 ease_factor |
| `interval_before` | `INTEGER` | 非空 | 本次更新前的 interval |
| `interval_after` | `INTEGER` | 非空 | 本次更新后的 interval |
| `created_at` | `DATETIME` | 非空 | 写入时间 |

---

## 4. `user_daily_plans`

每日复习计划（可选，方便前端展示今日任务）。

| 字段名 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `plan_id` | `TEXT` | 主键 | 计划主键 |
| `user_id` | `TEXT` | 非空，外键 | 用户 |
| `plan_date` | `DATE` | 非空 | 计划日期 |
| `review_q_ids_json` | `TEXT` | 非空 | 今日待复习题目 ID 列表（JSON） |
| `new_q_ids_json` | `TEXT` | 可空 | 今日新题 ID 列表（JSON，可为空） |
| `review_limit` | `INTEGER` | 非空，默认 50 | 今日复习上限 |
| `new_limit` | `INTEGER` | 非空，默认 20 | 今日新题上限 |
| `completed_review` | `INTEGER` | 非空，默认 0 | 已完成复习数 |
| `completed_new` | `INTEGER` | 非空，默认 0 | 已完成新题数 |
| `created_at` | `DATETIME` | 非空 | 计划生成时间 |

唯一索引：`UNIQUE(user_id, plan_date)`

---

## 5. 关系

| 关系 | 约束 |
|---|---|
| `user_question_progress.user_id` → 用户表 | 非空 |
| `user_question_progress.q_id` → `questions.q_id` | 非空 |
| `study_review_logs.session_id` → `mock_interview_sessions` | 可空 |
| `study_review_logs.session_question_id` → `mock_interview_questions` | 可空 |

---

## 6. 索引建议

| 表 | 索引 | 用途 |
|---|---|---|
| `user_question_progress` | `UNIQUE(user_id, q_id)` | 一题一行 |
| `user_question_progress` | `(user_id, next_review_date)` | 当日待复习查询 |
| `study_review_logs` | `(user_id, review_date)` | 学习报告/趋势统计 |
| `study_review_logs` | `(q_id, review_date)` | 题目历次得分曲线 |
| `study_review_logs` | `(user_id, review_context, review_date)` | 区分场景的统计 |
| `user_daily_plans` | `UNIQUE(user_id, plan_date)` | 一天一份 |
