## 1. 范围

围绕 Prompt 版本的质量评估闭环：
- **被动指标**：从 Playground 修正率、生产抽取拒绝率自动统计。
- **主动评估**：A/B 测试框架，同帖子并排两个 prompt 版本运行。
- **半自动优化**：基于 `item_corrections` 数据生成微调样本。

---

## 2. 被动质量指标

| 指标 | 计算方式 |
|---|---|
| 接受率 | `accepted / (accepted + rejected + corrected)` 按版本聚合 |
| 修正率 | `corrected / total` |
| 拒绝率 | `rejected / total` |
| 平均修正字段数 | `avg(len(corrected_fields))` |
| 平均置信度 | `avg(experiment_items.confidence)` |
| Token 成本 | 按版本聚合 token_input + token_output |
| 平均延迟 | 按版本聚合 latency_ms |

---

## 3. A/B 测试框架（待实现）

```
选定一批 artifact（如 100 条）
   │
   ▼
版本 A 与版本 B 并行运行
   │
   ▼
人工评分（接受 / 拒绝 / 修正）
   │
   ▼
对比两版本指标，选出胜者
```
