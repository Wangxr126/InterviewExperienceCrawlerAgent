## 3. B6 题库后台维护

| 功能 | 说明 |
|---|---|
| 全库搜索 | 按 q_id / 题干关键词 / 来源 URL |
| 字段修正 | 直接编辑题干 / 答案 / 公司 / 岗位 / 难度 / 题型 / 标签 |
| 状态变更 | active / hidden / merged / deleted / archived |
| 强制归组 | 把两道题手动设为同组 |
| 强制拆分 | 从组内移除某题 |
| 重新建图 | 触发 `graph.build.queue` 重建 |
| 重新建向量 | 触发 `vector.build.queue` 重建 |
