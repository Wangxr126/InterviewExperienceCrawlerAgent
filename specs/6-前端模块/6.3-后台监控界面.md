## 2. 全局结构

- 入口路径：`/admin/observability`，仅 admin 可访问。
- 视情况嵌入 Grafana / Phoenix / Jaeger UI（iframe / 链接），不重复造轮子。
- 自研页面只覆盖业务相关指标（C9 / C10 / C11 / 部分 C6）。

---

## 3. AgentScope / LlamaIndex 集成策略

| 工具 | 用途 | 集成方式 |
|---|---|---|
| **AgentScope Studio** | C6 Agent 调试与回放 | 开发期直连；生产期可在管理后台嵌入或保留链接 |
| **AgentScope tracing/hooks** | C5 token 用量数据源 | 自动落 `llm_call_audit` |
| **LlamaIndex Callback Manager** | C7 检索回放数据源 | 自动落 `retrieval_event` |
| **Phoenix（Arize）/ Langfuse** | C7/C8 检索回放与评估 UI | 嵌入或独立部署，按 [A-002](../0-总览/0.1-未决问题与TODO清单.md) 决定 |
| **LlamaIndex Evaluation** | C8 Hit Rate / NDCG | 周期任务跑评估，写入业务表 |
| **Jaeger / Tempo** | C4 链路追踪 UI | OTel SDK 接入即可 |

---

## 4. 数据流概览

```
业务请求
   │
   ├── OTel SDK ──► Jaeger / Tempo （C4）
   ├── 结构化日志 ──► Loki + Grafana （C1, C2, C3）
   │
   ├── AgentScope hooks ──► llm_call_audit ──► C5
   ├── LlamaIndex callback ──► retrieval_event ──► C7
   │
   └── 周期任务
        ├── 图谱健康指标 ──► C9
        ├── 数据质量统计 ──► C10
        └── SM-2 健康 ──► C11
```
